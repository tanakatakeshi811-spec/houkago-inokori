# 放課後の居残り

ブラウザだけで遊べる 3D 鬼ごっこゲーム。インストール不要、スマホでもPCでも遊べる。

**▶ 遊ぶ: https://tanakatakeshi811-spec.github.io/houkago-inokori/**

## どんなゲーム?

放課後の校舎に閉じ込められた生徒4人 vs 先生1人。

- **生徒**: 黄色い机の課題プリントを5枚仕上げて、昇降口から脱出する
- **先生**: 生徒に課題を叩きつけてダウンさせ、反省椅子に座らせる

生徒でも先生でもプレイできる。相手側はAIが動かす。

## みんなで遊ぶ(オンライン対戦)

タイトル画面左のアイコンから「オンライン」を選ぶと、友達と一緒に遊べる。

- **部屋を作る**(ホスト): 4桁の部屋コードが出るので、友達に伝える。先生役はホストだけが担当できる
- **コードで入る**(参加者): もらったコードを入れて入室。空いている生徒枠に入る
- 人数が足りない枠は今まで通りAIが埋める(2人でも4人でも遊べる)
- 通信は PeerJS(ブラウザ同士が直接つながるP2P)。サーバー代はかからない
- ホストのPCが全部の判定(当たり判定・課題の進み具合など)を計算する。ホストの回線が
  試合を支えているので、ホストが落ちると試合も終わる
- 参加者の操作は「動きは自分の画面ですぐ反映、それ以外(攻撃・課題・スキルなど)は
  ホストの返事を待ってから反映」という作り。わずかに遅れて感じることがある
- 試合中の途中参加はできない。部屋は1試合ごとに解散するので、続けて遊ぶ時は
  もう一度部屋を作り直す

## 操作

### PC

| キー | できること |
|---|---|
| W A S D | 移動 |
| Shift | 走る |
| マウス | 視点 |
| E / 左クリック | 行動(課題・救助・攻撃) |
| F | 隠れる・乗り越え・板を倒す |
| Q | 固有能力 |
| R | 能力2 |
| F / J 連打 | もがく・こらえる |
| 1 | チャット(合図)を開く。ホイールかカーソルキーで選び、クリック/Enterで送信。送信後3秒はクールダウン |
| 2 | マイクのオン/オフ(オンライン対戦中のみ) |

### スマホ(横画面推奨)

黄色い枠の中だけでスティックが動く。押した場所がそのまま基準点になり、
離すまで基準点は動かない(離すと外れる)。水色の枠は視点操作ゾーン。
能力・能力2・隠れる・走る・行動ボタンは右側(左手モード設定時は左側)にまとまる。
合図(チャット)ボタンはボタン群の上あたりに配置。
設定(右上の歯車)でボタンの大きさや左右反転を変えられる。

## ボイスチャット

オンライン対戦中、キー「2」(またはマイクの表示自体をタップ)でマイクのオン/オフを切り替えられる。
近くにいる人ほど大きく、離れるほど聞こえなくなる近接ボイスチャット。
画面上部中央にマイクのオン/オフが表示される。マイクは全員が直接WebRTCでつながる方式で、
サーバーは経由しない(初回はブラウザからマイクの使用許可を聞かれる)。

## 中身

素の HTML + JavaScript 1ファイル。3D描画に three.js (CDN) を使っているだけで、
ビルドもサーバーも要らない。`index.html` をブラウザで開けばそのまま動く。
